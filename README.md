# Weather (Дневник погоды)
**Автор:** [Александр] [Святкин]
**Язык:** Python 3.13

## Описание программы

Графическое приложение (GUI) для ведения дневника погоды. Позволяет добавлять записи о погоде за определённую дату с указанием температуры (°C), текстового описания и наличия осадков.
Программа поддерживает фильтрацию записей по дате и температуре. Все данные сохраняются в файл формата JSON для долговременного хранения.
Приложение разработано с использованием библиотеки Tkinter.

## Технологии

*   **Python:** 3.13 (язык программирования).
*   **Tkinter:** стандартная библиотека для создания графического интерфейса.
*   **JSON:** формат хранения данных.
*   **Git:** система контроля версий.
*   **GitHub:** платформа для хостинга репозитория.

## Как запустить приложение

1.  Установите Python 3.13 (если не установлен).
2.  Скачайте или склонируйте этот репозиторий.
3.  Откройте терминал (командную строку) в папке проекта.
4.  Запустите приложение командой:
    ```bash
    python weather.py
    ```
    *Если команда не работает (например `python` не найден), попробуйте:*
    ```bash
    python3 weather.py
    ```
5.  Пользуйтесь!
> *Для работы приложения не требуются сторонние библиотеки (`pip install`), так как используются только стандартные модули Python.*
